# 王者竞技场 · 网页版 MOBA

一款可直接在浏览器中游玩的 MOBA 对战游戏，玩法致敬经典手机 MOBA（推塔、兵线、技能、经济、摧毁水晶获胜），**手机 / 平板 / 电脑三端通玩**。

> 所有英雄、名称与美术素材均为程序化绘制的原创内容，零外部资源依赖，可完全离线运行。

## 快速开始

```bash
cd honor-of-kings-web
npm start          # 启动本地服务器
# 浏览器打开 http://localhost:8080
```

也可以用任意静态服务器（如 `python3 -m http.server`）托管本目录，或直接部署到 GitHub Pages / Vercel 等平台。

## 玩法

- **阵容**：3v3，你 + 2 名 AI 队友对阵 3 名 AI 敌人
- **目标**：沿兵线推进，摧毁敌方两座防御塔后击碎水晶即获胜
- **成长**：击杀小兵/英雄获得经验与金币，自动升级属性、自动升阶装备
- **英雄**：剑魂（战士·突进收割）/ 星澜（法师·范围爆发）/ 风羽（射手·持续输出），各有 2 个普通技能 + 1 个大招

## 三端操作

| 平台 | 移动 | 普攻 | 技能 | 回城 |
|------|------|------|------|------|
| 电脑 | WASD / 方向键 | 空格 或 J | K · L · U | B |
| 手机/平板 | 左侧虚拟摇杆 | 右下攻击键 | 右侧技能键 | 回城键 |

界面自适应屏幕尺寸，刘海屏安全区已适配。

## 三端进度同步

战绩档案自动保存在本机（localStorage）。跨设备同步：在选人界面点击**导出同步码** → 复制到另一台设备 → **导入同步码**，战绩自动合并（取较大值，不丢进度）。

## 运行测试

```bash
npm test
```

37 项自动化测试覆盖：

- 数学工具与伤害/经验/装备公式
- 出兵、击杀结算、复活、回城、防御塔、泉水回复、胜负判定
- 技能释放（冷却 / 蓝耗 / buff 生效与过期）
- AI 行为（撤退、追击、放技能、不干扰玩家输入）
- 存档读写、同步码导入导出、跨设备合并
- 浏览器入口冒烟测试（仿真 DOM 跑完整游戏循环 700 帧）

## 代码结构

```
js/core/    游戏核心逻辑（纯 JS，无浏览器依赖，可在 Node 中模拟整局）
  constants.js  数值配置    utils.js   数学工具
  heroes.js     英雄定义    combat.js  战斗公式
  game.js       状态机主循环 ai.js     机器人 AI
  save.js       存档与同步
js/ui/      浏览器表现层
  input.js      键鼠 + 触屏摇杆统一输入
  renderer.js   Canvas 渲染（地形/单位/特效/小地图）
  hud.js        血条/技能冷却/比分/播报
js/main.js  入口与对局流程
tests/      自动化测试
```
